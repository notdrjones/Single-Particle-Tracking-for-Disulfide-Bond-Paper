# Single-Particle-Tracking-for-Disulfide-Bond-Paper
Scripts used to analyse the output of thunderSTORM localisation of single particle fluorescence microscopy data. Localisations are linked into tracks, filtered, and then plotted in multiple different formats in both 2D and 3D. 
The overall_tracking_plotting script allows users to set the values of parameters that are used during the analysis (e.g. max memory, max search distance) and to establish the path to the files being analysed. All scripts are intended for use on data that is organised into subfolders such that all acquisitions from each sample are placed into a folder labelled with the sample name. Running the script will produce a results folder in which the outputs are split into similarly organised sub-folders based on sample, and then based on individual acquisition (this helps when dealing with large numbers of particles to trace a trajectory back to the raw video). Smoothing of the data by generating a rolling average of localisations +/- x frames from the raw localisation is also possible by changing the 'smoothness' parameter x.

NB there is a check for the first letter of the acquisition file name to eliminate irrelevant .tif files, but this can be removed if unnecessary.
